# Thomas Clarke

Nuxt 3 portfolio foundation for [thomasclarke.studio](https://thomasclarke.studio).

About and North Star copy live in `content/about.js` and `content/north-star.js`. Project names live in `content/projects.js`.

## Development

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:3000.

## Production build

```bash
npm run build
npm run preview
```
